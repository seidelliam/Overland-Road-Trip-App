# Road Trip Planner — Project Requirements

I want an interactive map that will save routes for a specific trip, and can both give ideas for the routes via scrapping and maybe an LLM, as well as allow you to save specific locations you want to hit along the route.

## Goals
Should make planning much easier, side by side comparisons of multiple routes for the same trip, provide good suggestions, and also have really impressive UI. 


## Trip Details
You can ask how many travelers, what the dates would be, but neither of these are going to be deal breakers, just things that could potentially be thrown into a prompt


## Core Features
Be able to save multiple routes (seperated by trip), multiple stops on the route, keep track of budget. Also, keep track of the overnight stays spots, as well as any stops that will be made along the way. Utilize AI and web scrapping to gather ideas for the routes that are already selected.
